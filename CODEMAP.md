# CODEMAP.md — muốn đổi X thì sửa ở đâu

> Bảng tra cứu nhanh cho XBoss. Khác `docs/ERD.md` (schema DB) và `docs/adr/` (quyết định kiến
> trúc) — file này trả lời **"chạm vào đâu, rồi chạy lại gì để tự kiểm"**. Không thay thế việc đọc
> `CLAUDE.md` cho quy ước đầy đủ.

| Muốn                                                                     | Sửa                                                                                                                | Rồi chạy                                                                             |
| ------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------ |
| Thêm sheet tracking mới                                                  | `POST /api/sheets` (không sửa `lib/nen/sheets.ts` — chỉ còn dùng backfill 5 sheet gốc)                             | kiểm slug unique trong `sheet_types`                                                 |
| Đổi logic tính % tiến độ/status task                                     | `lib/tien-do/recompute.ts` + `lib/tien-do/status.ts` (vùng rủi ro cao, xem `docs/audit.md`)                        | `npx tsx --test tests/recompute.test.ts` + `npm run test:mutation`                   |
| Đổi quyền/vai trò                                                        | `lib/nen/roles.ts` (map `CAN`) + `lib/bao-mat/auth.ts`                                                             | `npm run check:route-perms`                                                          |
| Thêm route API mới                                                       | `app/api/<đường-dẫn>/route.ts` — luôn `getCurrentUser()` + 401 + `export const dynamic = "force-dynamic"`          | `npm run check:route-perms` + `npm run check:project-scope`                          |
| Đổi schema DB                                                            | file mới `migrations/000N_*.sql` (append-only, idempotent `IF NOT EXISTS`)                                         | `npm run check:migrations` + `npm run db:migrate -- --dry-run` + `npm run gen:erd`   |
| Thêm/sửa module `lib/`                                                   | đúng miền theo `lib/layers.json` (ADR-0007) — không tạo `utils/`                                                   | `npm run check:lib-layers`                                                           |
| Đồng bộ vật tư hai chiều với Google Sheet                                | `lib/vat-tu/material-sync.ts` + `lib/vat-tu/google-sheets.ts`                                                      | `npx tsx --test tests/material-sync.test.ts`                                         |
| Đổi luồng nghiệm thu 2 bước                                              | `app/api/tasks/[id]/approve/route.ts` + `app/api/approvals/route.ts`                                               | test approvals liên quan + `docs/audit.md` vùng rủi ro cao                           |
| Đổi ngưỡng cảnh báo (trễ hạn, tồn kho, chi phí...)                       | bảng `alert_rules` qua `lib/van-hanh/alerts.ts` (không hardcode ngưỡng trong route)                                | kiểm `/api/notifications` trả đúng loại cảnh báo                                     |
| Thêm loại thông báo mới                                                  | `lib/dich-vu/thong-bao.ts` (dedup theo khoá riêng + unique index một phần)                                         | verify qua UI `NotificationBell`                                                     |
| Đổi màu/theme UI                                                         | biến CSS trong `app/globals.css` (`html.light`) — KHÔNG dùng `dark:`, KHÔNG hardcode hex                           | `npm run check:contrast` + `npm run check:mau-accent` + `npm run check:hex-hardcode` |
| Thêm nút/thẻ/chip mới                                                    | tái dùng `app/components/ui/` (Button/Card/Chip/Section/StatCard) trước khi viết mới                               | review theo ADR-0009                                                                 |
| Đổi export Excel/PDF                                                     | `/api/export/excel` hoặc trang `/report` (in-friendly)                                                             | verify bằng mắt file xuất ra                                                         |
| Đổi cron báo cáo ngày/tuần                                               | `app/api/cron/daily-report` / `weekly-report` — xác thực `CRON_SECRET` qua header Bearer                           | test route trực tiếp với header giả                                                  |
| Thêm biến môi trường mới                                                 | schema zod `lib/nen/env.ts` (nguồn sự thật đầy đủ) **+** tóm tắt trong `CLAUDE.md`                                 | `npm run build` (env thiếu bắt buộc phải throw đúng chỗ)                             |
| Đổi logic import Excel gốc                                               | `lib/tien-do/import.ts` (nhận diện hàng nhóm vs sub-task theo pattern mã)                                          | `npm run db:seed` trên file mẫu trong `attachments/`                                 |
| Thêm/sửa cổng CI static mới                                              | `scripts/check-<tên>.ts` **+** thêm bước trong job `static` của `.github/workflows/ci.yml`                         | `npm run check:<tên>` chạy cục bộ trước khi push                                     |
| Sửa hook Claude Code (chặn git nguy hiểm, gate commit)                   | `.claude/hooks/<tên>.sh` **+** khai trong `.claude/settings.json`                                                  | thử gọi lại đúng lệnh bị chặn, xác nhận hook trả exit 2                              |
| Thêm/sửa subagent (route: complex/spec/standard/mechanical)              | `.claude/agents/<tên>.md` (frontmatter `description` nêu route + model/effort)                                     | không có cổng máy — review bằng mắt, đối chiếu bảng route trong `CLAUDE.md`          |
| Merge một PR xong, quay về `main`                                        | cập nhật `PROGRESS.md` (mục "Đã làm"/"Tiếp theo", số PR) — bắt buộc theo `CLAUDE.md`                               | `npm run check:progress-freshness` (job CI, chỉ chạy khi push vào `main`)            |
| Ghi bẫy vừa mắc / tra bẫy cũ trước khi debug lỗi lạ                      | `TRAPS.md` (gốc repo)                                                                                              | không có cổng máy — review bằng mắt khi duyệt PR                                     |
| Bảo trì định kỳ (dependency lỗi thời, PROGRESS.md lỗi thời, nợ kỹ thuật) | chạy `/maintain` — xem `.claude/commands/maintain.md` + `.claude/agents/maintainer.md`                             | `bash scripts/maintenance-sweep.sh`                                                  |
| Rà soát diff trước khi mở PR                                             | `/review` — xem `.claude/commands/review.md`, gọi skill `code-review` (+ `security-review` nếu chạm vùng nhạy cảm) | agent `reviewer` (`.claude/agents/reviewer.md`)                                      |
